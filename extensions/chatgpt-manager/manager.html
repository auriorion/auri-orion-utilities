Eliminar lote real de ChatGPT

Atención: esta operación eliminará las conversaciones de tu cuenta de OpenAI, no solo de este catálogo. La eliminación no se puede deshacer. Puede incluir conversaciones personales o recientes si las has seleccionado. El método visual utiliza menús; el método de sesión utiliza una API web interna no documentada y requiere consentimiento separado.

Borrado por ID y cuenta. Probado con éxito en tu cuenta. No depende del menú lateral, del título ni de que ChatGPT muestre mensajes. Utiliza una ruta interna de ChatGPT no documentada. Antes de solicitar cada eliminación verifica la cuenta y el ID exacto (nunca depende del título); tras la solicitud comprueba el resultado. Puede dejar de funcionar si OpenAI cambia la web. No guarda tokens y no reintenta eliminaciones inciertas.

Si cambia la interfaz, no carga un chat, o no podemos comprobar su identidad, se detendrá el lote. No hace falta ir uno por uno.
