# Soporte · Auri–Orion MCP Browser

Para comunicar errores y sugerencias, utiliza [GitHub Issues](https://github.com/auriorion/auri-orion-utilities/issues). Indica versión de la extensión, versión de Chrome, sistema operativo, descripción y pasos de reproducción.

**No publiques** contraseñas, tokens, URL privadas, capturas con datos personales, registros de sesiones o detalles internos de organizaciones.

El servidor MCP es un componente local y no una API web pública. Consultar [instalación](extensions/auri-orion-mcp-browser/docs/INSTALACION.md) y [privacidad](PRIVACY.md) antes de activarlo.
